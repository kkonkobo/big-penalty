Ce que fait l'application

Une recherche, une vingtaine de sites

LinkedIn, Indeed, Welcome to the Jungle, HelloWork, APEC, France Travail, JobTeaser et d'autres, interrogés d'un coup à partir de votre profil.

Classées selon votre profil

Chaque offre reçoit un score et une explication. Les compétences demandées comptent comme des souhaits, pas comme des conditions : seuls le contrat et le lieu écartent une offre.

Les plus récentes d'abord

Les offres de plus de 14 jours sont écartées et les plus fraîches remontent. Les offres republiées sont signalées.

Sans doublons

La même offre vue sur plusieurs sites n'apparaît qu'une fois, avec tous les sites où elle a été trouvée.

Le site de l'entreprise

Quand il existe, le lien vers l'offre sur le site de l'entreprise est retrouvé, pour postuler à la source.

Tout reste sur votre ordinateur

Pas de compte. Vos profils et vos offres restent en local. Le score par IA utilise vos propres clés Anthropic ou OpenAI ; sans clé, des règles prennent le relais.

Installation

L'application n'est pas signée par un certificat payant : Windows et macOS affichent un avertissement au premier lancement. Voici comment le passer. Google Chrome doit être installé : la recherche s'en sert pour consulter les sites d'emploi.

Windows

  1. Lancez le fichier téléchargé, Big-Penalty-windows-x64-setup.exe.
  2. Si Windows a protégé votre ordinateur s'affiche : Informations complémentaires, puis Exécuter quand même.
  3. Suivez les étapes. Aucun mot de passe administrateur n'est nécessaire.
  4. Ouvrez Big Penalty depuis le menu Démarrer ou le Bureau.

Mise à jour : lancez simplement le nouvel installateur. Il remplace l'ancienne version ; vos profils et vos offres sont conservés.

macOS

  1. Ouvrez le fichier téléchargé, puis glissez Big Penalty dans Applications.
  2. Ouvrez l'application une première fois : macOS la bloque.
  3. Allez dans Réglages Système › Confidentialité et sécurité, puis cliquez Ouvrir quand même. Sur macOS 14 ou plus ancien, un clic droit sur l'application puis Ouvrir suffit.

Mise à jour : glissez la nouvelle version dans Applications et remplacez l'ancienne.

Clés d'IA (facultatif)

  1. Au premier lancement, l'application crée un fichier .env dans son dossier de données :
    Mac : ~/Library/Application Support/Big Penalty
    Windows : %LOCALAPPDATA%\Big Penalty
  2. Ouvrez-le avec un éditeur de texte et collez votre clé après ANTHROPIC_API_KEY= ou OPENAI_API_KEY=.
  3. Redémarrez Big Penalty.

Ce fichier reste sur votre ordinateur. Ne le partagez pas.
